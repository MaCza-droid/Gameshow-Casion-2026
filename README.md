# General structure
Branches are used to create new Variations before changing the current final programm in the Main Branch
# How to use
Make changes on your local machine and test the *.tex* file before commiting **only** the *.tex* file. The final *.pdf* will be generated by me.
## Which branch to use
If the *Proposed-Changes* branch is at the same state as the *main* branch use it else create a new branch from *main*
